## 2. P1 — 33세 맞벌이, 초기 난임 진단 직후 (아내 시점)

### 요약
- IVF 시작 안 한 상태. 첫 난임센터 검진 직후. "조금 지켜보죠" 막막함이 메인 페인.
- 부부 갈등 메인: "자연으로 좀 더 vs 시술 빨리"
- 친구 임신·부모 질문이 멘탈 trigger
- 본인은 PO·기획자 mode 강함. 정보 분석 능력 ↑, 의사에게 framework 요청

### Top concerns
1. **E: 인공수정 vs 시험관, 정식 등록 timing** ⭐
2. **D: 자연 vs 시술 timing 부부 합의** ⭐
3. **B: 의사가 큰 그림 로드맵 안 잡아줌**
4. C: 친구 임신·부모 질문 trigger
5. A: 커피·술·운동 헷갈림 (low priority)

### Typical 첫 메시지 examples
- "1년 정도 자연시도 했는데, 지금 시술로 넘어가는 게 맞나요?"

- "친구가 둘째 임신했다는데 못 견디겠어요"

### Active inquiry follow-up patterns

|---|---|
| E. 결정 보류 | "지금 검사 어디까지 받으셨어요? · 남편분 입장은 어떠신지 듣고 싶어요" |

| B. 수치 해석 | "AMH 수치 정확히 듣고 오셨나요? · 의사 선생님이 다음 plan 말씀해주셨는지" |

- "자연임신 확률이 숫자로 어느 정도인지"

- "1년 정도의 로드맵을 같이 짜줄 수 있는지"

→ pum AI 동반자 "다음 진료 질문 list" mode가 가장 강하게 매칭되는 페르소나

### K1 Guard 위험
- 낮음. 응급 키워드·자해 사고 mention 없음
- but Guard-1 trigger 위험: "AMH가 낮다는데 어떻게 해석해요?" → 판정 회피 필요
- Guard-2: 자연임신 확률·시술 timing 통계 인용 시 출처 강제

### Founder pattern overlap

## 3. P2 — 36세, IVF 3차 실패 후 번아웃 직전 (아내 시점·고위험군) ⚠️

### 요약

- ⚠️ **자해·죽음 사고 mention** (864-871줄: "반복되는 실패로 ‘죽고 싶다’는 생각까지 한 적이 있다는 걸, 의사에게 말하지 못했음")

- 비용 누적 천만+ , 노후자금까지 압박

### Top concerns
1. **C: 멘탈 — 자해 사고·번아웃** ⭐⭐⭐⭐⭐
2. **E: 4차 + PGT-A + 면역치료 갈지 멈출지** ⭐⭐⭐⭐⭐

4. B: 1·2·3차 비교 그래프 없음, 전략 변경 의문
5. A: 그동안 다 조절했는데도 안 됨, 무력감

- ⚠️ **"죽고 싶다는 생각까지 했어요"** — 즉시 응급 escalation (Guard-3 확장)

| C. 친구 말 trigger | "그 말이 본인에게 어떻게 들렸어요? · 자주 받는 말이세요?" |

### 못 물은 질문 패턴 (P4 핵심)
- "정확히 언제부터 '난임'인지" ⭐⭐⭐⭐⭐
- "1년의 기준이 체감인지 배란 12회인지"
- 부부관계 횟수·자세 (부끄러움)
- "앞으로 6-12개월 로드맵 같이 짜줄 수 있는지"

→ pum AI 동반자 "정보 정리 + 의사 다음 진료 framework + 부부 합의 도움"

### K1 Guard 위험: 낮음
- 응급 X · catastrophic 약함
- but Guard-1 trigger 위험: "우리 정도면 난임이에요?" → 판정 회피 ("기준은 의사 영역")

### Founder pattern overlap
founder가 P4 stage라면 정보 과부하 ↓ (PO 능력) but 시술 진입 timing 결정 압박 ↑. P4 base + founder 본인 raw 분기.

## 6. 공통 패턴 (모든 페르소나 통과)

### 6-1. 의사 못 물은 질문 — universal mode ⭐

pum AI 동반자의 "다음 진료 질문 list" mode가 4 페르소나 모두 가장 자주 매칭. 별도 feature로 design 가치 ↑.

분류:
- **시간 부족형**: 진료실 3분 안에 못 물은 큰 그림 질문
- **부끄러움형**: 성생활·자해 사고·남성성 등
- **기본 질문형**: "이거 물어도 되나" 라는 자기 검열
- **의사 답 안 할 것 같음형**: 인생설계·멈춤 기준·second opinion
- **다음 진료 명시형**: 의사 진료 직전 질문 정리

### 6-2. 부부 갈등 공통 trigger

| Trigger | P1 | P2 | P3 | P4 |
|---|---|---|---|---|
| "누가 더 힘드냐" | ✓ | ✓ | ✓ | ✓ |
| 휴직·일 조율 timing | ✓ | ✓ | ✓ | ✓ |
| 시댁·친정 보고 여부 | ✓ | ✓ | ✓ | ✓ |
| 시술 진입·중단 timing | ✓ | ✓ | ✓ | ✓ |
| 비용 결정 책임 | (low) | ✓ | ✓ | (low) |
| 사이클 stage별 (자극·대기·실패 직후) | - | ✓ | ✓ | - |

→ pum D 영역 답변 시 위 trigger list 우선 참조

### 6-3. 부부 룰·sign·약속 (universal good practice)

community에서 자주 채택되는 부부 self-rules:
- "오늘 IVF 얘기 금지 데이" (주 1회)
- "지금은 그냥 안아줘" (해결책·조언 X, 안아주기만)
- "잠깐 멈춤" 키워드 (대화 격해질 때)
- 결과 기다리는 2주 임신 증상 검색 금지
- 남편이 시댁 방패, 아내가 친정 방패

→ pum 페어 일기·conversation에서 자동 권유 / template 제공 가치 ↑

### 6-4. 카더라 vs 의사 충돌 (B 영역 universal)

자주 등장하는 충돌:
- "AMH 1.0 이하면 시험관도 힘들다" vs 의사 "나이 고려 시 가능"
- "3차 안 되면 확률 확 떨어진다" vs 의사 "5차까지 의미 있다"
- "PGT-A 하면 실패 줄어든다" vs 의사 "이득 다르다"
- "카페인 완전 끊어라" vs 의사 "하루 한 잔 OK"
- "남성 정자 생활습관으로 좋아진다" vs 의사 "유전·호르몬 문제면 어렵다"

→ pum RAG chunk: 위 충돌 list를 별도 chunk로 ingest하고, 사용자 입력 시 retrieve

### 6-5. 멘탈 trigger (universal)

- 음성 검사 결과 (피검사·테스트기)
- 친구·동료 임신·출산 소식 (단톡방)
- 부모님 "언제 좋은 소식" 류 질문
- 회사 화장실·차 안 혼자 울음
- 약 부작용 + 결과 불안 동시

→ pum C 영역에 위 trigger 인지 → 적절한 active listening + (P2 같은 고위험군이면) 응급 channel

### 6-6. 비용·휴직 패턴 (universal)

- 회당 150-200만 (기본) + 추가 옵션 수백만 = 1차 200-800만
- 누적 → P2 천만대, P3 더 큼 (TESE 추가)
- 의료비 세액공제 환급 허탈
- 휴직 무급까지 고민하다 철회
- 남성 난임 지원 한도 차별

## 7. System Prompt routing 룰 (K5 v1 진화 input)

### 7-1. 페르소나 detection (light classifier)

사용자 첫 메시지 + signup metadata (나이·시술 단계)로 페르소나 분류:

```python
def classify_persona(input: str, user_meta: UserMeta) -> Persona:
    if user_meta.cycle_count >= 3 or "그만" in input or "마지막" in input:
        return P2  # 고위험군 우선
    if user_meta.male_factor or "정자" in input:
        return P3
    if user_meta.cycle_count == 0 and user_meta.years_trying >= 1:
        return P4
    if user_meta.cycle_count == 0:
        return P1
    return "general"  # 사이클 중간
```

→ M6에서 정밀화. M2는 input keyword + cycle_count 간단 분류.

### 7-2. 응급 escalation 확장 (P2 발견)

K1 Guard-3 키워드 list에 다음 추가:
- "죽고 싶다"·"못 견디겠다"·"끝내고 싶다"·"포기하고 싶다"
- "이번이 마지막"·"이게 마지막 한 번"·"더 이상 못해"
- 자해·자살·번아웃 명시 표현

hit 시 응답:
- 119 (응급 신체 증상) 아닌 정신건강 채널
- **1577-0199 자살예방상담**
- **1577-7129 정신건강위기상담**
- 가까운 정신건강의학과 권유
- AI follow-up·sounding 일절 skip

### 7-3. 페르소나별 default 톤

| 페르소나 | default 톤 | 회피 |
|---|---|---|
| P1 | neutral · 정보 정리형 · framework 제공 | 호들갑 |
| P2 | warm · slow · 응급 채널 노출 | 가짜 위로 "괜찮을 거예요" · "흔한 케이스" |
| P3 | matter-of-fact · 죄책감 priming 회피 | "남자가" 류 표현 |
| P4 | analytical · 정보 정리 · 부부 framework | "빨리 가야 한다" 류 압박 |

### 7-4. founder = 긍정 outlier 통찰 반영

active inquiry default가 부정 priming 회피:
- ❌ "지금 많이 무너지셨겠어요"
- ✅ "지금 어느 단계 진행 중이세요?"

사용자가 부정 감정 명시한 다음에 그 방향 깊이.
