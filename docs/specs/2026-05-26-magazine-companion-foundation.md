# 매거진형 동반자 — 기반 + 홈 (첫 조각) 설계

> **작성** 2026-05-26 · **상태** 설계 합의 완료(브레인스토밍) → 구현 계획 대기
> **맥락** pum을 "로그인·회원가입·AI 대화"만 있는 빈약한 상태에서 **"혼자도 곁에 두고 매일 들춰보는 따뜻한 매거진형 동반자"**로 확장하는 큰 방향의 **첫 조각(①기반 + ②매거진 홈)**. 전체 비전은 5조각(①기반+홈 ②콘텐츠 ③위로 ④커뮤니티 ⑤AI고도화)으로 분해됨 — 이 spec은 ①+②만 다룬다.

---

## 0. 한 줄

혼자서도 쓸 수 있게 구조를 열고(self-space), 따뜻·포근한 톤으로 갈아입히고, **사이클 단계에 맞춘 매거진 홈 + 핵심 콘텐츠 4종**을 얹어 "차가운 SaaS"를 "지친 부부 곁의 동반자"로 바꾼다.

## 1. 목표와 비범위

**목표**
- 가입 즉시 **혼자서 콘텐츠·대화·기록을 다 쓸 수 있다** (페어는 선택).
- 앱 전체가 **따뜻·포근**한 톤 (크림 배경·테라코타 포인트·둥근 카드·부드러운 폰트).
- 홈이 **사이클 단계에 맞춰** "지금 도움될 글"을 보여준다.
- 매거진 콘텐츠 **4 카테고리**(꿀팁·마음·부부·장소)를 마크다운으로 채운다.

**비범위 (후속 조각)**
- 커뮤니티(다른 부부 글·감정 공유) — Phase 2
- 위로·실패 케어 전용 흐름 — ③조각
- 용어집, do/don't 외 카테고리 확장 — ②후속
- 풀 사이클 트래커(날짜 계산·알림) — M3
- 관리자 글쓰기 페이지(CMS) — 콘텐츠 쌓인 뒤
- AI 대화 고도화(콘텐츠 연계·개인화) — ⑤조각

## 2. 화면 구조 — 하단 4탭 (모바일 우선)

| 탭 | 경로 | 내용 |
|---|---|---|
| 🏠 홈 | `/home` (또는 `/`) | 맞춤형 — 인사 + 사이클 단계 + "지금 도움될 글" + 대화 유도 |
| 📚 글 | `/articles` | 매거진 본체 — 카테고리별 콘텐츠 목록/상세 |
| 💬 대화 | `/chat` | AI 동반자 (기존, 혼자도 가능) |
| 👤 나 | `/me` | 사이클 단계 설정 · 배우자 연결(선택) · 설정·로그아웃 |

- 기존 상단 헤더 네비 → **하단 탭 바**로 전환(모바일 한 손 조작). 데스크톱은 상단 또는 좌측.
- 로그인 후 기본 진입 = 홈.

## 3. 혼자 쓰기 (self-space)

**문제** 현재 `getCoupleForUser`가 페어 없으면 `null` → 대화·기록 시작이 막힘.

**설계** 기존 couple 구조를 **재사용**하되, 가입한 사람은 **자기만의 1인 couple(self-space)**을 자동으로 갖는다.
- **가입(또는 첫 진입) 시 self-couple 자동 생성**: `couples`(created_by=본인) + `couple_members`(본인) 1행. → `getCoupleForUser`가 항상 couple_id 반환. `personal_context`·`ai_chats`·`diary_entries` 모두 이 couple_id로 동작.
- **페어 연결**: '나' 탭에서 초대/수락. 수락 시 두 self-space를 **병합**(한쪽 couple로 합치고 빈 couple 정리 — 기존 M1.5 `acceptInvite` 패턴 확장). 데이터 이관 규칙은 구현 계획에서 확정.
- RLS·격리 패턴은 기존 couple 단위 그대로 유지(추가 테이블 없음).

**핵심 변경**: `chat/new`의 "먼저 배우자와 연결해주세요" 차단 제거(혼자도 couple 있으므로 통과).

## 4. 사이클 단계

- 저장: `personal_context.cycle_stage`(이미 존재, `text`). 이번에 **read 전용 → write 추가**.
- 값(라벨): `pre`(준비 중) · `stim`(난소자극) · `retrieval`(채취 후) · `transfer`(이식 후) · `wait`(결과 대기) · `result`(결과 확인). 미설정 허용(null).
- 입력: '나' 탭에서 단계 하나 선택(라디오/칩). 풀 트래커(날짜·차수·약물)는 M3 — 지금은 **단계 라벨 하나만**.
- 용도: 홈의 콘텐츠 매칭 + 인사 문구. (정확한 "D-day"는 날짜 데이터가 없으므로 이번엔 **단계 라벨 위주**, 날짜 표현은 M3 이후.)

## 5. 콘텐츠 그릇 (파일 기반, 나중 CMS 대비)

- 위치: `content/articles/*.md` (저장소 내 마크다운).
- frontmatter: `slug`, `title`, `category`, `cycle_stages`(배열, 빈 값=전체), `summary`, `published`(bool), `order`.
- 본문: 마크다운 (K1 의료법 톤 가이드 적용된 검증 글, founder 작성).
- 읽기 모듈: `lib/content/` — 목록/단건/카테고리·단계 필터를 **하나의 인터페이스**로. (나중 DB·관리자 CMS로 갈 때 이 인터페이스 뒤만 교체하면 화면은 그대로.)
- 1차 카테고리 4종: `tips`(꿀팁·do/don't) · `mind`(마음 돌봄) · `couple`(부부·남편 가이드) · `places`(함께 갈 곳, 부석사 류).
- AI 자동 생성 금지(의료법 리스크) — 검증된 글만.

## 6. 따뜻·포근 톤

`docs/ui-audit/2026-05-26` 감사 결과 반영. Tailwind v4 테마(`app/globals.css`)와 컴포넌트 토큰 교체:
- 배경 크림(예 `#fdf8f4`), Primary 테라코타/로즈(예 `#c8796a`), 보조 텍스트 따뜻한 회갈색.
- 카드 radius 확대, 그림자 부드럽게, 줄간격 1.8.
- 폰트 Pretendard(본문) — 현 시스템 폰트에서 교체.
- empty state·카피 따뜻하게: "아직 대화가 없어요" → "오늘 어떤 마음이세요?", 로그인/가입 수직 중앙 정렬 + 여백.

## 7. 홈 (맞춤형)

- 상단: 따뜻한 인사 + 현재 사이클 단계 라벨("다원님, 지금은 *채취 후*예요 🌱").
- "지금 도움될 이야기": 현재 `cycle_stage`와 매칭되는 콘텐츠 3~5개(매칭 없으면 카테고리 대표글).
- "오늘 마음은요?" 대화 유도 카드 → `/chat`.
- **미설정/콘텐츠 부족 fallback**: 일반 추천(최신·대표 글) + "단계 설정하면 더 맞춰드려요" 안내.

## 8. 데이터·구조 변경 요약

| 변경 | 내용 |
|---|---|
| self-couple 자동 생성 | 가입/첫 진입 시 1인 couple 생성 (마이그레이션 trigger 또는 앱 로직 — plan에서 확정) |
| `personal_context` write | cycle_stage 설정 mutation 추가(현재 read만) |
| 콘텐츠 모듈 | `content/articles/*.md` + `lib/content/` read 인터페이스 |
| 테마 | `app/globals.css` 따뜻 톤 토큰 + Pretendard |
| 네비 | 상단 헤더 → 하단 4탭 |
| 페어 차단 제거 | `chat/new` 등 couple 강제 분기 정리 |

## 9. 테스트 시나리오 (수용 기준)

1. **혼자 가입 → 즉시 사용**: 가입 직후 페어 없이 홈·글·대화 진입 가능, "배우자 연결" 차단 없음.
2. **사이클 단계 맞춤**: '나'에서 단계 설정 → 홈 "지금 도움될 글"이 그 단계로 바뀜. 미설정 시 일반 추천.
3. **콘텐츠 열람**: 글 탭 카테고리별 목록 → 상세 렌더(마크다운).
4. **따뜻 톤**: 주요 화면이 크림/테라코타 톤, 모바일 하단 탭 동작, empty state 따뜻한 카피.
5. **페어 연결(선택)**: '나'에서 초대/수락 → 두 공간 병합, 기존 데이터 유지.
6. **회귀**: 기존 단위/E2E(가드·RLS·대화) 통과.

## 10. 후속 조각 (이 spec 이후)

②콘텐츠 확장(용어집 등) → ③위로·실패 케어 → ⑤AI 대화 고도화 → ④커뮤니티 → 관리자 CMS. 각 조각은 별도 spec → plan.
