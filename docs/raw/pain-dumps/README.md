# 페인 dump 모음

본인 부부(다원·아내)의 IVF 진짜 페인·질문·고민·결정·다툼을 raw 그대로 흘려넣는 공간.

> **목적**: pum의 AI 동반자(W2)가 generic 안 되게, founder 부부 실제 패턴을 system prompt·RAG·UX 디자인에 직접 심기 위함. 본인 부부 = 1차 페르소나 + raw material.

---

## 어떻게 쓰면 되나

### 1. 진입장벽 0 — 형식 자유
- 한 줄도 OK
- 음성받아쓰기 paste OK
- 카톡 대화 paste OK
- 일기 prose OK
- 메모장 텍스트 paste OK
- 다듬을 필요 없음. 오타·반말·욕설 다 OK

### 2. 파일 이름 규칙
```
YYYY-MM-DD-{이름}.md     (예: 2026-05-14-다원.md)
YYYY-MM-DD-{이름}-{주제}.md  (예: 2026-05-14-다원-비용.md)
YYYY-MM-DD-부부.md        (둘이 같이 쓰는 거)
```

날짜는 dump 한 날짜. 같은 날 여러 번 하면 `-2`, `-3` 붙이거나 한 파일에 누적.

### 3. 가능하면 frontmatter 한 줄 (선택)
파일 맨 위에 이거 한 줄 있으면 나중에 분류·검색 편함:

```markdown
---
date: 2026-05-14
author: 다원 | 아내 | 부부
mode: dump | retro | 결정 | 감정
tags: [영양, 멘탈, 비용, 부부갈등, 의사결정, 실패대응, 정보]
---

여기부터 raw 내용...
```

frontmatter 없어도 됨. 본문만 있어도 OK.

## 어떤 걸 쓰면 좋나 (영감용 — 따를 필요 없음)

CLAUDE.md §1에 정리된 8 페인을 frame으로 쓰되, **본인 부부 실제 케이스 디테일이 핵심**:

1. **일상 do/don't** — 영양·습관·운동·수면. 헷갈리는 거, 검색했는데 답 다른 거
2. **정자·난자 질 개선 시도** — 어떤 시도 했나, 효과 의심, 의사 답변 부족
3. **시술 성공 확률** — 어떤 변수에 신경 쓰나, 카더라 vs 의학
4. **멘탈** — 무너지는 순간, 회복 패턴, 약 부작용
5. **부부 갈등** — 다툰 이슈, 책임 분담, 휴직·일 조율
6. **"이게 맞나" 의사결정** — 차수·휴식·병원 변경·중단
7. **"안되면 어떡하지"** — 실패 시나리오, 다음 카드
8. **정보 비대칭·카더라** — 어디서 헷갈렸나, 어떤 정보가 진짜였나

### 좋은 dump 예시 (가공)
- "지난 화요일 저녁, 아내가 '이렇게 주사 맞으면서까지 해야 하나' 했음. 위로하려다 '그럼 안 할거야?' 나왔고 30분 다툼. 결론은 다음 사이클까지 가기로. 아내는 호르몬 + 회사 스트레스 겹친 듯."
- "오늘 검사 결과 AMH 1.2. 작년 1.5였는데 떨어진 거라 의사한테 물었더니 '나이 들면서 자연 감소'라고만. 추가 시도 없을지 물었어야 했는데 못 물어봄. 집에 와서 검색 → 갑상선·비타민D·DHEA 자료 봤는데 의견 갈림. 카더라 의심됨."
- "회당 비용 750만. 1차 실패. 2차 갈지 말지 — 정부지원 1회 남음. 아내가 휴직 중이라 우리 수입은 1.5에서 1. 6개월 쉬고 다시 할지, 바로 2차 갈지. 시간(나이) vs 돈 trade-off."

### 짧은 dump도 가치 있음
