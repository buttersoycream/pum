## A. 인스타 버전 (5 카드)

### 카드 1 — Hook
```
[헤드 카피]
"아내랑 둘이서 IVF를 시작한 지 [N]개월.
앱 하나가 빠진 채로요."
```
- 톤: 짧고 직설. 페인 statement.
- 이미지: 손글씨 두 줄 · 빈 약병 옆 캘린더 · 알람 시계 · 등 (실명·얼굴 X)

### 카드 2 — 우리는 누구
```
저는 [N]년차 기획자.
아내는 [직군 한 단어].
한국에서, 아이를 기다리는 평범한 부부예요.

[N]차 시도 중이고,
이제 우리 IVF 여정을 공개하면서
같은 길 가는 부부들과 함께
앱 하나를 만들어보려 합니다.
```
- 톤: 자기소개 + 의도.

### 카드 3 — 왜 공개하나
```
검색하면 카더라뿐.
의사는 3분 만남.
일반 임신앱은 IVF를 모르고.
영문 앱은 한국 의료를 모르고.

그래서 만듭니다.
실제 사이클·비용·결정·감정을 공개하면서.
```
- 톤: 페인 + 솔루션 hint. 비교 X (어떤 앱이 나쁘다는 표현 X)

### 카드 4 — 무엇을 공개하나
```
공개합니다:
✓ 회당 비용·정부지원·본인부담
✓ 약 종류·일정·부작용
✓ 검사 수치·등급 (의학 해석은 의사에게)
✓ 부부 갈등·의사결정·무너졌던 순간

공개하지 않습니다:
✕ 이름·얼굴
✕ 병원·의사
✕ 지역
```
- 톤: 익명 transparency 명시. 신뢰 자산.

### 카드 5 — CTA
```
'품(pum)' — 안다·품다·기다리다.

한국 IVF 부부의 동반자 앱을 만드는 중.
질문 던지고 같이 고민하는 AI 동반자 + 부부 일기.

같이 갈 부부는 link in bio.
출시 시 우선 invite.
```
- CTA: link in bio (구글폼·Tally 등)

### 캡션 (카드 밖)
```
처음 시작은 [년] [월] [둘 중 한 명] 검진실에서였습니다.
"한 번 시도해볼 시간이 됐어요."

그날 이후 [N]개월, [N]차 사이클까지 왔고,
이제는 우리만 알고 있는 게 아니라
같은 길 가는 부부들과 공유하고 싶어졌습니다.

이 계정에서는 우리 IVF 여정을 익명·실데이터로 timeline 공개하고,
같은 길 가는 부부들이 동반자 앱 '품(pum)'을 같이 만들어요.

매주 2-3번 timeline post. 본인부부 사이클 진행 상황 따라.

#IVF #시험관 #난임 #난임부부 #체외수정 #배아이식
```

## B. 블로그 long-form 버전

```markdown
# 안녕하세요, 아이를 기다리는 한국 부부입니다 — IVF [N]차 진행 중, 동반자 앱 '품(pum)'을 만들고 있어요

## 우리 둘 (간단히)

저는 한국에서 일하는 [N]년차 기획자입니다. 아내는 [직군 한 단어]이고,
저희는 결혼한 지 [N]년차, IVF [N]차 사이클을 진행 중이에요.

이름·얼굴·병원·지역은 공개하지 않습니다. 대신 수치·비용·일정·감정·결정
모든 raw 데이터는 시간 따라 공개할 예정이에요.

왜 그렇게 정했는지는 아래에 정리합니다.

## 왜 이 글을 시작하나

IVF 시작한 [N]개월 전, 저희가 겪은 문제는 한 가지예요.

**필요한 정보가 어디에도 정리된 형태로 없다는 것.**

- 의사 진료는 3분. 검사 결과 받고 다음 질문 정리하기엔 너무 짧아요.
- 맘카페·블로그는 카더라가 절반. 어떤 정보가 진짜인지 분간하기 어렵습니다.
- 일반 임신앱은 IVF 사이클·약·일정을 모르고, 영문 IVF 앱은 한국 의료수가·지원금·휴직 제도를 모릅니다.
- 그래서 매번 검색·통화·메모를 직접 끌어모았어요. 효율도 떨어지고, 부부끼리도 정보가 어긋났습니다.

저희가 같은 길 가는 부부들에게 줄 수 있는 가장 가치 있는 것은
**저희 실제 데이터를 익명으로 공개하는 것**이라는 결론에 도달했습니다.

그리고 그 데이터를 바탕으로 동반자 앱 '품(pum)'을 만드는 중이에요.

## '품(pum)'이 뭐예요

한국 IVF 부부의 동반자 앱이에요. 핵심 기능:

1. **AI 동반자** — 질문을 받기만 하지 않고, **던지는** AI. "양주 한 잔 마셔도 되나?" 같은 막연한 질문에 본인의 사이클 단계·맥락을 캐묻고 정리해줍니다. (의사 진료의 대체가 아니라, 다음 진료 질문 list를 준비하는 동반자)
2. **부부 일기** — 부부 둘 다 보이는 공유 일기 + 본인만 보이는 private 일기.
3. **비용·지원금 정리** — 회당 비용·정부지원·본인부담·세금공제 한 곳에.
4. **사이클 트래커** — 주사·검사·시술 일정 + 부부 알림.
5. **Founder Diary** — 저희 부부 timeline 앱 안 통합.

저희가 사용자이자 founder예요. 다른 IVF 부부와 함께 만들고 다듬어가려고 합니다.

## 무엇을 공개하나 / 공개하지 않나

**공개**
- 회당 비용·정부지원·본인부담 (구체 금액)
- 사이클 차수·단계·약 종류·시술 일정
- 검사 수치 (AMH·FSH·정자분석·내막두께·배아 등급 등) — 단, **의학적 해석은 담당 의사 영역**입니다. 저희는 수치 자체만 공개합니다.
- 부부 갈등·결정·무너졌던 순간 — 감정 raw 그대로
- 정부 지원금 신청 절차·휴직 제도 운용 결과

**공개하지 않음**
- 저희 이름·얼굴·구체적 직장
- 병원·의사 이름
- 거주 지역 (시·도 수준 식별 가능 정보 X)
- 가족·친지 식별 가능 정보

이 익명 가이드는 다른 IVF 부부 베타 사용자에게도 동일하게 적용됩니다.

## 의료법·정보 면책 (중요)

- 저희가 공개하는 모든 정보는 **저희 부부 본인 사례**입니다.
- 다른 부부에게 같은 시술·약·방법을 권하지 않습니다.
- 통계나 수치를 인용할 때는 출처와 날짜를 함께 표기합니다.
- 의학적 판단·진단·처방은 **담당 의사 영역**입니다. 저희는 정보 정리·기록·일정 관리에 한정합니다.

## 다음 글 계획

이 계정·블로그에서는 주 2-3회 timeline 글을 쓸 예정이에요. 이미 정해진 주제:

- 1차 채취일 — 비용·약·일정·감정 raw
- [N]차 회당 비용 분석 — 정부지원 받기 전·후
- 휴직 결정 — 회사 협의·소득 변화·부부 합의
- 무너졌던 화요일 저녁 — 그날 무슨 일이 있었나
```

## C. user가 채워야 할 [BRACKETS] (체크리스트)

- [ ] `[N]년차 기획자` → 본인 직군 (예: "9년차 PO/기획자")
- [ ] `[직군 한 단어]` → 아내 직군 (식별 어렵게 broad하게)
- [ ] `[N]개월` → IVF 시작 후 경과 (대략)
- [ ] `[N]차` → 현재까지 사이클 차수
- [ ] `[년] [월] [둘 중 한 명] 검진실` → 시작 시점 — 구체적이지만 식별 불가하게
- [ ] 베타 대기명단 link 결정 (구글폼·Tally·landing page)
- [ ] 인스타 계정명·블로그 도메인 결정
- [ ] 카드 이미지 5장 디자인 (canva 등)
- [ ] SEO 키워드 추가 (블로그)
- [ ] 발행 시간 결정 (인스타는 평일 저녁·주말 오전 권장)
