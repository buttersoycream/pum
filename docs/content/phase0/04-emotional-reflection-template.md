# Template 04 — Emotional reflection post (감정 reflection)

> 가장 raw하고 가장 신뢰 자산 만드는 콘텐츠. K1 §6-5 감정 언어 가드 strict.

---

## A. 인스타 버전 (3-5 카드)

### 카드 1 — Hook (한 줄)
```
지난 화요일 저녁,
아내가 30분 울었어요.

[한 줄 raw]
```
- 톤: 호들갑 X. fact statement.
- 이미지: 빈 식탁·세면대 거울·창밖·등 (얼굴 X, 손도 X 권장)

### 카드 2 — 그날 무슨 일이 (factual)
```
[저녁 N시]. [어떤 trigger인지 한 줄.]

원래 그건 [별 일 아닌 것 / 늘 있던 일]이었는데,
이번엔 무너졌어요.

호르몬 [N]일차였고,
아내는 [어떤 약·부작용].
```

### 카드 3 — 본인 perspective (남편 또는 아내)
```
처음엔 [본인이 한 반응].
잘못된 거 알면서도.

[N]분 지나서야
"미안해. 안아도 돼?"

아내가 다시 [한 줄].
```
- 톤: 본인의 부족함 인정 OK. "이해해줘"가 아니라 본인 회고.

### 카드 4 — 무엇이 [그날] 회복시켰나
```
그날 [무엇이 도움됐는지 한 줄].
[누구 / 무엇 / 시간].

[N]시간 / [N]일 걸렸어요.
```

### 카드 5 — CTA
```
IVF는 호르몬+불확실+비용+시간이 동시.
부부 둘 다 어딘가 무너지는 순간이 옵니다.

같이 가는 부부 모집 — link in bio.
```

### 캡션
```
지난 화요일 저녁, 30분 같이 울었어요.

호르몬 [N]일차, [어떤 trigger] 때문에 [한 줄].
회복까지 [N]시간 걸렸고, 다음 날 부부끼리 한 마디 정리했어요.

raw 감정 dump이지만, 같은 길 가는 부부에게
"우리만 이런 거 아니구나" 했으면 해서 올립니다.

호르몬 부작용·부부 갈등은 IVF 일상이에요.

#IVF #난임부부 #IVF감정 #호르몬부작용 #시험관일기 #부부갈등
```
