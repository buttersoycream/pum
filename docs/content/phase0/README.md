# Phase 0 콘텐츠 템플릿 — Founder's Diary 시작 패키지

> founder 부부 IVF 익명 timeline을 인스타·블로그에 publish하기 위한 5개 template + 톤 가이드 + publish 워크플로.
>
> **목적**: 시드 audience 500-1000명 확보 (4-8주). 콘텐츠 = 마케팅 CAC 0원에 가까운 angle.
>
> **상태**: 2026-05-14 v0. user가 본인 부부 timeline에 맞춰 수정·publish.

## 1. 핵심 원칙 (CLAUDE.md §위험·spec §10·K1 가드 종합)

### 정서 (brand soul)
- **"아이를 함께 기다리는 둘"** — couple은 means, child-longing이 end
- 톤: **간절·따뜻·솔직**. 호들갑 X. "이겨내자" X. "괜찮을 거야" X
- 안다 · 품다 · 기다린다

### 익명화 가드

| | 공개 OK | 공개 X |
|---|---|---|
| 수치 | AMH · FSH · 등급 · 확률 | |
| 비용 | 실비용 · 지원금 · 본인부담 | |
| 단계 | 사이클 차수 · 약 종류 · 시술 일정 | |
| 감정 | 모든 raw 감정 | |
| 관계 | "아내" · "남편" · "어머니" | 실명 X |
| 의료기관 | | 병원명 · 의사명 X |
| 위치 | | 지역명 · 동·구 식별 X |

### 의료법 가드 (K1)
- 본인 사례 = OK (1차 자기 정보)
- 일반화·다른 부부에게 추천 = X
- 통계 인용 시 출처 + "일반 통계, 본인 케이스 다를 수 있음"
- "성공률 ~%"·"이 방법이 좋다" 등 결과 보장 X
- 의사 의견·진단·처방 publish X (의사 못 함, "이런 안내 받았다" OK)

## 2. 5개 Template

| # | 형식 | 인스타 사용 | 블로그 사용 |
|---|---|---|---|
| 01 | Intro post — 우리 부부 소개 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 02 | Cycle event — 1차 채취일 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 03 | Cost breakdown — 회당 비용 분석 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ (SEO) |
| 04 | Emotional reflection — 무너졌던 저녁 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| 05 | Decision sounding — 2차 갈까 쉴까 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ (SEO) |

각 template은:
- **인스타 버전** (3-5 카드, 카드당 50-150자) — 감정·이미지 중심
- **블로그 long-form** (1500-3000자) — SEO·정보 정리·analysis 중심
- **[BRACKETS]** 표기는 user가 본인 부부 실제 내용으로 교체할 자리

## 3. Publish 워크플로

```
1. founder 부부가 timeline event 발생 (예: 1차 채취일)
2. user (다원·아내)가 raw dump → docs/raw/pain-dumps/
3. user가 해당 template 선택 → 본인 부부 내용으로 교체 → 익명화
4. (선택) claude가 K1 톤 가드·익명화 review
5. (Phase 0 후반) 법무 자문 1차 OK
6. publish:
   - 인스타: 카드 3-5장 + 캡션
   - 블로그: long-form + SEO 메타
   - 베타 대기명단 CTA 끝에 부착
```

### Publish 빈도 가이드

- 주 2-3회 (CLAUDE.md §위험에 명시)
- 1주 = 인스타 2 + 블로그 1 권장
- 사이클 event 발생 직후가 가장 진정성·SEO 둘 다 좋음

## 4. 채널별 best practice

### 인스타

| 요소 | 가이드 |
|---|---|
| 카드 수 | 3-5장 (1장 hook · 2-4장 본문 · 5장 CTA) |
| 카드당 글자 | 50-150자 (스마트폰 한 화면) |
| 이미지 | 실명·얼굴 X. 손·물건·풍경·일러스트 OK. 알약 패키지 OK (라벨 안 보이게) |
| 해시태그 | #IVF #시험관 #난임 #난임부부 #체외수정 #IUI #배아이식 |
| CTA (5장) | 베타 대기명단 link in bio 안내 |
| 캡션 | 300-500자, 첫 줄에 hook |

### 블로그 (SEO)

| 요소 | 가이드 |
|---|---|
| 글자 수 | 1500-3000자 |
| H2·H3 | 3-7개 |
| 키워드 | "IVF 1차 비용" · "시험관 채취일" · "난임 지원금" 등 long-tail |
| 내부 link | timeline 다른 post와 cross-link |
| 외부 link | 보건복지부·KSRM 등 공식 출처 |
| CTA | "같이 갈 부부 모집" 베타 대기명단 |

## 5. 베타 대기명단 CTA 표준 문구

(여러 곳에서 일관 사용)

```
─────────────────────────────
🤝 같이 가는 부부를 모집합니다

'품(pum)'은 한국 IVF 부부의 동반자 앱이에요.
질문 던지고 같이 고민해주는 AI 동반자 + 부부 일기 + 비용·지원금 정리.

founder 부부 본인 IVF 진행 중. 익명·실데이터 공개하면서 만드는 중.
관심 있는 부부는 베타 대기명단에 [link] — 출시 시 우선 invite.
─────────────────────────────
```

링크는 user 결정 (구글폼·Tally·landing page 등).
