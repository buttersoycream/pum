## A. 인스타 버전 (4 카드)

### 카드 1 — Hook
```
[1차 결과 한 줄] 후,
지금 우리는 결정 보류 중입니다.

"2차 바로 갈까,
6개월 쉬고 갈까,
병원 옮길까."
```

### 카드 2 — 우리가 고려한 변수
```
저희가 같이 펴본 변수 6가지:

1. 나이 (시간)
2. 정부지원 잔여 회차
3. 부부 컨디션·관계
4. 1차 protocol 적합도
5. 비용 한도
6. 직장·휴직 status
```

### 카드 3 — 무게
```
가장 무겁게 weigh한 건 [무엇].
가장 적게 weigh한 건 [무엇].

근거: [한 줄]
```

### 카드 4 — 결정 (또는 보류)
```
이번 주말까지 결정합니다.
[N월 N일]에 결정 결과 별도 글 올려요.

품(pum) — link in bio.
```

### 캡션
```
IVF [N]차 실패 후, "다음 차수 vs 휴식 vs 병원 변경" 결정 중.

우리가 펴본 변수 6가지, 무게 분배, framework 공유해요.
완벽한 정답 아니고, 저희 부부 사례.

다른 부부도 자기 framework 만드는 데 참고 됐으면 합니다.

#IVF #시험관2차 #난임결정 #IVF의사결정 #난임부부
```
