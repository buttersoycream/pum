# Phase 0 콘텐츠 — 페르소나별 hook variation

> 기존 5 template (01-05)의 Card 1 (Hook)과 SEO 키워드·블로그 제목을 4 페르소나 (P1-P4)별로 분기.
>
> **Source**: K7 `docs/knowledge/sub_personas.md` 4 페르소나 분석.
>
> **목적**: 다른 stage의 IVF 부부가 각자 검색·SEO·인스타 hashtag로 founder Diary에 만나는 entry point 분리. CTR · trust · conversion 다 분리 최적화.
>
> **founder 부부 = 긍정 outlier**: founder 본인 톤은 별도 vertical로 분리 ("긍정 부부도 IVF 결정·비용·정보 마주한다"의 contrast).

---

## 0. 페르소나별 검색 의도·hook target

| 페르소나 | Stage | 검색 의도 | hook target |
|---|---|---|---|
| **P1** (초기 진단) | pre-IVF | "난임센터 가야 하나" "AMH 낮다 의미" | 정보·로드맵 |
| **P2** (반복 실패) | 3차 후 ⚠️ | "IVF 3차 실패" "그만둘까" | 결정 framework · 위로 (간접) |
| **P3** (남편·정자) | 남성난임 | "정자 운동성" "남성난임 지원" | 남성 perspective · 책임 |
| **P4** (정보 과부하) | 자연시도 1년+ | "1년 안 되면" "난임센터 첫 방문" | 정리·합의 framework |
| **Founder Diary** (긍정 outlier) | 본인 부부 timeline | 본인 부부 만나는 검색 외 | 신뢰 자산 · 정보 transparency |

## 1. Template 01 (Intro) — 페르소나별 변주

### P1 — pre-IVF 초기

**인스타 Card 1**:
```
"AMH 낮다는 말 들었는데
머리가 새하얘진 분.

혼자만 그런 거 아니에요."
```

**블로그 제목 후보**:
- "난임센터 첫 방문 — AMH·FSH·정자검사 어디까지 받아야 하나"
- "1년 자연시도 후, 난임센터 가야 하는 신호 5가지"

**SEO 키워드**: 난임센터 첫 방문, AMH 낮음, 자연임신 시도 기간, 난임 진단 기준

---

### P2 — 반복 실패 ⚠️

**인스타 Card 1**:
```
"3차 실패. 그만둘까 한 번만 더 갈까.
이 결정에 답이 없다는 걸 압니다.

다만 같이 생각해줄 누군가는 있어야 해요."
```

⚠️ **톤 가드 strict**:
- 호들갑 X
- "이겨내자" X
- 결과 보장 X
- 응급 채널 footnote 부착 (인스타 캡션 또는 블로그 끝)

**블로그 제목 후보**:
- "IVF 3차 실패 후 — 우리 부부 결정 framework (6 변수·무게 분배)"
- "그만둘 기준 — 다른 부부들의 의사결정 패턴 정리"

**SEO 키워드**: IVF 3차 실패, 시험관 그만두기, 난임 번아웃, 시험관 4차

**필수 부착 (블로그 끝)**:
```
※ 마음 너무 무거우시면 혼자 안고 계시지 마세요.
- 자살예방상담: 1577-0199 (24시간)
- 정신건강위기상담: 1577-7129
- 가까운 정신건강의학과
```

---

### P3 — 남편·정자 이슈

**인스타 Card 1**:
```
"남편 정자 문제로 ICSI 했어요.
미안한데 말은 못 했어요.

남편들 어디까지 짊어지고 있나요."
```

**블로그 제목 후보**:
- "남편 시점 IVF — 정자 이슈, 죄책감, 부부 mediation"
- "남성난임 지원 한도 — 한국 정책의 여성 기준이 남편에게 미치는 영향"

**SEO 키워드**: 남편 정자 검사, ICSI, TESE 비용, 남성난임 지원, 정자 운동성

---

### P4 — 자연시도 1년+ 정보 과부하

**인스타 Card 1**:
```
"1년 시도 했는데 다음이 막막.
카페·블로그·유튜브 다 봤는데 더 헷갈려요.

정리해야 결정할 수 있더라고요."
```

**블로그 제목 후보**:
- "1년 자연시도 후 — 인공수정 vs 시험관 결정 framework"
- "난임센터 첫 방문 전 — 부부 합의 8 체크리스트"

**SEO 키워드**: 1년 안 되면, 인공수정 시험관 차이, 난임센터 가는 시점, 부부 합의

### Founder Diary (긍정 outlier) — 별도 vertical

**인스타 Card 1**:
```
"무너지지 않은 부부의 IVF 기록.
근데 결정·비용·정보는 똑같이 마주합니다.

founder 부부 timeline 공개합니다."
```

**블로그 제목 후보**:
- "긍정적인 부부도 한국 IVF 한복판에서 마주하는 것들 — founder 부부 timeline"
- "PO·기획자 부부의 IVF — 한국 시스템·비용·결정을 raw하게"

**SEO 키워드**: founder IVF 일기, 익명 IVF 기록, 한국 IVF 부부 timeline

**positioning**: 다른 4 페르소나가 어두운 페인에서 만나는 entry라면, founder Diary는 "긍정 부부도 IVF 정보 비대칭·결정 마찰을 마주한다"의 정보 trust angle. 위안보다 분석.
