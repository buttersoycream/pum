# Template 02 — Cycle event post (사이클 event)

> "1차 채취일" 양식. 다른 event (이식일·결과일·검사일·약 시작일 등)도 동일 구조 응용.

---

## A. 인스타 버전 (4 카드)

### 카드 1 — 오늘 무슨 날
```
오늘은 [N차] 채취일이었습니다.

[새벽 N시] 일어나서 마지막 trigger 주사.
[N시] 병원 도착, [N시] 시술 시작.
[N시] 회복실 깨고, [N시] 집에 왔어요.

난포 [N]개. 채취된 난자 [N]개.
```
- 톤: factual timeline. 감정은 카드 3에.

### 카드 2 — 약·비용
```
오늘 사용된 약:
- [Gonal-F N IU × N일]
- [Cetrotide × N일]
- [Ovidrel trigger]
- [기타]

비용 (오늘 한정):
- 시술비: [N]만원
- 약: [N]만원
- 마취·기타: [N]만원
정부지원 차감 후 본인부담: [N]만원
```
- 톤: 숫자 raw.

### 카드 3 — 감정
```
회복실에서 처음 한 생각.
"끝났다"보다 "이제 시작이다".

[N]개 난자 중 정자 만나서
배아 되고, 등급 받고, 이식까지
3-5일 더 기다려야 해요.

아내는 약 부작용으로 [N]일 만에
오늘 처음 깊게 잤어요.
```
- 톤: 감정 솔직. 한 가지 raw 디테일.

### 카드 4 — CTA
```
다음 update는 [N월 N일] 배아 등급 결과.

품(pum) — 같이 가는 부부 모집 link in bio.
```

### 캡션
```
사이클 [N]차, 오늘 채취 끝났습니다.

난포 [N]개 자랐고, [N]개 난자 채취. 결과는 [N월 N일] 배아 등급으로 확인 예정.

오늘 비용·약·감정 다 카드에 정리했어요.

#IVF #채취일 #시험관 #난임 #난임부부 #1차사이클
```

```markdown

| 시간 | 이벤트 |
```

## C. 다른 event 응용 (동일 구조)

### 이식일
- 카드 1: 이식 timeline + 배아 등급
- 카드 2: 약 (progesterone·estradiol·기타) + 비용
- 카드 3: 감정 (이식 후 며칠 wait의 시작)
- 카드 4: 다음 hCG 결과일 CTA

### 검사일 (혈액검사·초음파 등)
- 카드 1: 무슨 검사·왜
- 카드 2: 결과 수치 raw (해석은 X)
- 카드 3: 감정·다음 진료 질문 list
- 카드 4: CTA

### 약 시작일
- 카드 1: 어떤 약·언제부터·왜
- 카드 2: 첫 자가주사 경험
- 카드 3: 초반 부작용
- 카드 4: CTA

### 결과일 (hCG·임신확인·실패)
- 가장 sensitive. 별도 톤 가이드 필요. K1 §6-5 "실패" 표현 회피.
- "이번 주기 미착상" (사실 description)
- 무너지는 감정 raw OK
- 다음 결정은 "다음 글에서 정리" (즉시 결정 발표 X)
